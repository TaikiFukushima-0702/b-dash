# Personal Life Planner

自己分析と人生設計のための記録ノートです。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `01_self-analysis.md` | 自己分析（性格・強み・弱み・価値観） |
| `02_vision-and-goals.md` | ビジョン・目標・やりたいことリスト（メイン） |
| `03_life-plan-timeline.md` | ライフプラン年表 |
| `04_notes.md` | メモ・振り返り |

## 使い方

1. 各ファイルのテンプレートに沿って、自分の言葉で記入してください
2. `<!-- ここに記入 -->` の部分を自分の内容に置き換えます
3. 定期的に見直して更新していきましょう
